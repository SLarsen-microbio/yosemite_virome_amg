# Analysis scripts

This directory contains the scripts used to reproduce the viral genome, auxiliary metabolic gene (AMG), abundance, and figure analyses reported in the Yosemite alpine lake virome/AMG study.

The repository contains analysis code and sample metadata. Raw sequencing reads, BAM files, and other large intermediate files are not stored in GitHub. Public data accessions and sample information are provided in `metadata/sample_metadata.tsv`. Users should supply local paths to downloaded or otherwise available input files as required by each script.

## Analysis workflow

Run the core analysis scripts in numerical order:

### `00a_qc_and_trim_reads.sh`

Performs read quality assessment and preprocessing prior to metagenome assembly.

The workflow includes:

- quality assessment of raw reads with FastQC v0.11.8
- paired-end read trimming with fastp v1.0.1
- automatic paired-end adapter detection using `--detect_adapter_for_pe`
- quality assessment of trimmed reads with FastQC
- aggregation of quality-control reports with MultiQC v1.30

Users supply the local directory containing downloaded or otherwise available paired-end FASTQ files.

### `00b_assemble_megahit.sh`

Assembles trimmed paired-end metagenomic reads independently for each sample using MEGAHIT v1.1.5.

Original analysis:

- paired-end assembly
- 16 threads
- otherwise default MEGAHIT parameters

The user supplies the sample identifier and paths to the paired trimmed read files when running the script.

### `00c_identify_viruses_virsorter2.sh`

Identifies viral sequences in assembled metagenomic contigs using VirSorter2 v2.2.4.

Original analysis:

- input contigs were pre-filtered to ≥1 kb
- minimum viral sequence length: 5000 bp
- 16 threads
- all viral groups enabled

Key parameters:

```text
--min-length 5000
-j 16
all
```

### `00d_quality_check_checkv.sh`

Assesses viral genome quality using CheckV v1.0.3.

Original analysis:

- `checkv end_to_end`
- 16 threads
- CheckV database v1.5

The user supplies the sample identifier, the VirSorter2 `final-viral-combined.fa` file, and the local path to the CheckV database.


### `01_dereplicate_viral_genomes.sh`

Dereplicates complete, high-, and medium-quality viral genomes using CD-HIT-EST v4.8.1.

Original analysis:

- Input: 909 complete-, high- and medium-quality viral sequences
- Clustering threshold: 95% nucleotide identity
- Minimum alignment coverage: 85% of the shorter sequence
- Output: 695 dereplicated viral species representatives

Key parameters:

```bash
-c 0.95
-aS 0.85
```

### `02_run_vibrant.sh`

Runs VIBRANT v1.2.1 on the 695 dereplicated viral species representatives to identify viral auxiliary metabolic genes.

Input:

- 695 dereplicated viral species representatives

Downstream analyses use the VIBRANT individual-AMG and AMG-pathway output tables.

### `03_map_reads_bowtie2.sh`

Maps paired-end metagenomic reads to the 695 dereplicated viral genome representatives using Bowtie2 v2.5.1.

The user supplies the sample identifier, paired trimmed read files, and viral genome FASTA when running the script.

Outputs include:

- sorted BAM file
- BAM index
- Bowtie2 mapping log

Run this script once for each metagenomic sample listed in `metadata/sample_metadata.tsv`.

### `04_calculate_rpkm_breadth.py`

Calculates viral genome abundance using a 75% breadth-of-coverage filtered RPKM approach.

For each sample:

1. Coverage breadth is calculated for each viral genome.
2. Genome detections with breadth below 75% are excluded.
3. Mapped reads are summed across genomes passing the breadth threshold.
4. RPKM is calculated using mapped reads on passing genomes as the sample-specific denominator.

The resulting matrix is used for downstream viral abundance and AMG analyses.

### `05_calculate_amg_fraction.py`

Calculates the fraction of viral community abundance attributable to AMG-carrying viral genomes.

For each sample:

- total viral RPKM is summed across all detected viral genomes
- AMG-carrying viral RPKM is summed across viral genomes containing at least one VIBRANT-identified AMG
- the AMG-carrying fraction is calculated as AMG-carrying RPKM divided by total viral RPKM

## Figure scripts

Scripts used to generate manuscript figures are located in `scripts/figures/`.

### `figure1_amg_abundance.py`

Generates manuscript Figure 1, corresponding to dissertation Figure 8.

The figure summarizes:

- total viral abundance divided between AMG-carrying and non-AMG-carrying viral genomes
- AMG-carrying viral genome abundance by KEGG metabolic category

Abundance is based on the 75% breadth-filtered RPKM matrix generated by `04_calculate_rpkm_breadth.py`.

### `figure2_amg_categories.py`

Generates manuscript Figure 2, corresponding to dissertation Figure 7.

The script summarizes the metabolic categories of the 789 AMG instances identified by VIBRANT across the 695 dereplicated viral genomes.

### `figure3_deazaguanine_cluster.sh`

Runs Pharokka v1.9.1 annotation used for manuscript Figure 3 panels A and B.

The analysis focuses on the `k141_70163` and `k141_11273` viral genomes containing deazaguanine-related gene clusters from the UC1 warming tFinal sample.

### `figure3_panelC_gene_cluster.py`

Generates the gene-neighborhood visualization for manuscript Figure 3 panel C using the Pharokka annotations.
